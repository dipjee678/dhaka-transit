About Dhaka Transit

Dhaka Transit is an open-source public transportation dataset and multimodal route-planning platform for Dhaka, Bangladesh. Because usable open GTFS feeds for Dhaka are virtually non-existent (our OSM snapshot found 0 usable bus route relations across all of Greater Dhaka), this project pairs a transparent, community-extensible GTFS data pipeline with clean implementations of real-world transit routing algorithms.

Dijkstra (Frequency-Based Graph)

Models each boarding stop S(p) and each route-direction stop R(r, d, p) as graph nodes. Staying on board costs only in-vehicle time; boarding incurs expected wait (headway / 2) plus a transfer penalty on subsequent boardings using an exact 1-bit (node, has_boarded) state.

  • Time-independent: answers "what is the typical best route?"
  • Powers untimed queries and graceful fallback outside operating hours.
  • Complexity: O((|V| + |E|) log |V|) with binary heap.

RAPTOR (Round-Based Transit Routing)

Operates directly on the timetable without a priority queue. Round k scans every route pattern serving stops improved in round k - 1, propagates transitively closed walking footpaths, and applies local & target pruning.

  • Calendar-exact: distinguishes Sat–Thu schedules from Friday afternoon MRT-6 service.
  • Returns a Pareto-optimal set trading off travel time against transfers.
  • Verified against an independent time-expanded Dijkstra oracle in automated tests.

A* Walking Optimization & Provenance Integrity

Admissible A* Pedestrian Search

transit/routing/astar.py implements A* on OpenStreetMap walkable street graphs using the great-circle haversine lower bound h(u, goal) = haversine_m(u, goal). Because straight-line distance never overestimates street distance, A* finds optimal walking paths while expanding strictly fewer nodes than Dijkstra.
